Cara menggerakkan
  1. Probe: klik kulit untuk menempatkan, seret probe untuk menggeser, atau pakai tombol arah (tahan untuk terus bergerak).
  2. Kamera: seret area kosong untuk memutar, Shift/klik kanan untuk menggeser, scroll untuk zoom. Kamera tidak pernah mengubah citra.
  3. Arah selalu arah tubuh pasien (Kanan/Kiri PASIEN), bukan arah layar. Arahkan kursor ke tombol arah untuk melihat panahnya di 3D.
Keyboard: ↑ ↓ superior/inferior · ← → kanan/kiri pasien · PgUp/PgDn anterior/posterior · Q/E putar · Shift = halus

Klik citra untuk memindahkan titik silang. Scroll pada citra menggeser irisan; seret menggeser tampilan, ⌘/Ctrl + scroll memperbesar. Kontrol di bawah juga menggeser irisan tanpa menyentuh citra.
