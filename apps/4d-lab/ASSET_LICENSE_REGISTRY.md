# Asset licence registry — MEDCOEL 4D Lab

Every non-code asset shipped from `apps/4d-lab` must be listed here before merge.

| Asset | Path | Origin | Licence / status | Redistribution |
|---|---|---|---|---|
| Synthetic phantom CT, labels, anatomy.json | `public/data/phantom/ct.nrrd`, `labels.nrrd`, `anatomy.json` | Generated by `pipeline/build_phantom.py` from original procedural geometry written for MEDCOEL | MEDCOEL original work (same terms as this repository) | Allowed (no patient data, no third-party geometry) |
| Phantom skin/organ meshes + registration | `public/data/phantom/skin.glb`, `organs.glb`, `registration.json` | Derived from the phantom CT/labels by `pipeline/reconstruct.py` | MEDCOEL original work | Allowed |
| Heart, breath and bowel sounds | runtime only (`src/sim/auscultation.js`) | Synthesised in code (damped oscillators, filtered noise) | MEDCOEL original work | Allowed; no recordings are used |
| three.js | npm dependency | mrdoob/three.js | MIT | Allowed |
| three-mesh-bvh | npm dependency | gkjohnson/three-mesh-bvh | MIT | Allowed |
| v0.9 prototype + its phantom | `legacy/v0.9/` | Earlier MEDCOEL prototype supplied by the project owner | MEDCOEL original work | Allowed (synthetic only) |

## Explicitly NOT included (and must not be added without written permission)
| Dataset / model | Reason |
|---|---|
| CTACardio (3D Slicer sample) | Cloud-processing and public redistribution rights not confirmed. Process locally only (`pipeline/README.md`, `local-data/`). |
| IT'IS Virtual Population (ViP) models or derivatives | Standard V2 licence does not permit public MEDCOEL deployment. |
| EchoNet-Dynamic videos/labels | Research-use agreement; no redistribution without authorisation. |
| TotalSegmentator licence keys / restricted weights | Academic credentials are private. Only run locally; never commit outputs from restricted tasks. |
| Recorded heart/lung sounds from third-party libraries | Not needed: sounds are synthesised. Any future recording needs an entry here with its licence. |

Tissue acoustic constants in `src/sim/tissues.js` are literature values (facts) cited in `MEDICAL_REFERENCES.md`.
