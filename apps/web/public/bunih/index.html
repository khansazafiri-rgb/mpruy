BUnih Finance membantu pemilik akun meninjau transaksi, mengelola tagihan berulang, memantau anggaran, dan mengoreksi catatan keuangan. Antarmukanya berupa dashboard web privat dan bot Telegram.

Baca kebijakan privasiKetentuan penggunaan

Gmail baca-saja

Dengan izin pengguna, BUnih memeriksa pesan keuangan yang relevan melalui Gmail API dan mengolah informasi transaksi atau tagihan. Aplikasi tidak mengirim, mengubah, maupun menghapus email.

Bot Telegram

Pemilik akun dapat meminta ringkasan atau mencatat transaksi secara manual. Akses bot dibatasi ke Chat ID yang didaftarkan.

Rekonsiliasi dan anggaran

Saldo terkonfirmasi, bukti pembayaran, kewajiban, dan proyeksi dikelola secara terpisah agar rencana keuangan tidak keliru dianggap sebagai transaksi aktual.

Dashboard privat

Data keuangan tidak dipublikasikan di website MEDCOEL. Dashboard BUnih berjalan sebagai layanan terpisah dan hanya tersedia bagi pengguna yang diberi akses.

Cara BUnih menggunakan data Google

BUnih hanya meminta scope gmail.readonly untuk membaca pesan yang mungkin berisi notifikasi transaksi, invoice, atau kuitansi. Informasi yang relevan diproses untuk catatan keuangan pengguna, bukan untuk iklan atau penjualan data. Pengguna dapat mencabut izin melalui akun Google ataupun halaman pengaturan BUnih.

Penggunaan informasi yang diterima dari Google APIs oleh BUnih mematuhi Google API Services User Data Policy, termasuk persyaratan Limited Use.

BUnih adalah alat bantu pencatatan pribadi, bukan bank atau layanan pembayaran. Aplikasi tidak dapat melakukan transfer uang. Pemilik akun harus memeriksa informasi dari bank sebelum mengambil keputusan keuangan.

Halaman ini bersifat informasi publik. Tidak ada login keuangan atau data akun pribadi yang ditampilkan di sini.
