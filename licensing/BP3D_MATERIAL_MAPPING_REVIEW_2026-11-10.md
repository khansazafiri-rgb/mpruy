## Code and generated review outputs

- One central tissue material scheme gives each confidently identified class a consistent color, roughness and nonmetallic response. Toggle between illustrative system color, tissue class and original neutral inspection. High contrast adjusts inexpensive lights; no fabricated textures or postprocessing are introduced.
- The viewer renders source geometry as double-sided, fully opaque and depth-writing. Normals and per-FJ bounds are checked read-only during conversion; small, thin, missing or invalid geometry is flagged in the generated inventory. Camera near/far values scale with the selected structure for small-element inspection. Source GLBs retain their existing hashes.
- Each full batch writes `mapping-review.json` and `mapping-review.csv` beside `inventory.json` and `mapping-gaps.json` under gitignored `local-data`. Every unmatched catalog entry gets one review row, with normalized Latin/English terminology, sidedness and explicit tissue-conflict checks, FMA/BP/FJ identity and source availability, a confidence **for human review**, and `approved: false`. The JSON groups totals by system and identifies duplicate direct identities. The original catalog and all 470 direct candidates remain intact.

## Limits and rights

The source is credited as BodyParts3D 4.0 from DBCLS under CC BY 4.0 in the existing pipeline, with exact upstream source hashes in each batch inventory. This does not clear the older Atlas application's CC BY-NC-SA code, mixed legacy model lineage, or derived 4D data. All commercial release and asset quarantine gates remain unchanged. No production routing or server operation is part of this work.
