# QA: "Cegukan: kenapa bunyinya hik?"
MP4 1080x1920, 30 fps, **46,20 dtk** (1386 frame = 900 edukasi + 486 master outro), H.264 + AAC 48 kHz stereo. Edukasi 0 - 30,0 dtk (narasi asli 0 - 27,8 dtk + ekor ringkasan 2,2 dtk); master outro 16,20 dtk ditempel utuh satu kali.

## Yang diperiksa dan hasilnya
- **Aset**: audio narator asli (ada), Raka resmi `raka.js` (ada), master outro (ada). Tidak ada aset pengganti. Audio asli 38,79 dtk memuat kalimat promosi lama; dipotong di jeda alami 28,20 dtk (sunyi 27,78 - 28,77). ASR ulang atas stem suara hasil potong: berakhir di "...yang jelas.", RMS 28,2 - 30,0 dtk = 0.
- **Frame pertama**: bergerak (selisih frame 0 -> 1 = 1,5; 0 -> 3 = 4,4 pada skala 0 - 255). Raka resmi sedang menulis, pensil bergerak, kamera mendorong masuk sejak frame 0; tidak ada logo diam.
- **Pacing (selisih frame, 900 frame edukasi)**: jeda diam terpanjang 17 frame (0,57 dtk); jendela 1 dtk paling sepi di 22,27 dtk (kartu pemicu tetap bergerak: sendok, lambung terisi).
- **Sinkron kata (waktu ASR + puncak energi)**: "hik" narator 5,13 dtk -> Raka tersentak di 5,13; "diafragma" 8,96 -> label DIAFRAGMA 8,90; "mendadak" 12,40 -> kontraksi 12,38 - 12,48; "menutup" 16,16 -> pita suara menutup 16,12 - 16,21; "hik" narator 19,74 -> pita suara menutup 19,66 - 19,75 + busur bunyi dan "HIK!" mulai 19,74; "Makan terlalu cepat" 21,08 -> kartu 21,04; "perut yang terlalu penuh" 22,22 -> kartu 21,95; "bisa memicu" 23,28 -> label 23,25; "cegukan" 24,14 / 26,0 -> Raka tersentak 24,12 / 26,3.
- **Efek "hik"**: satu efek sintetis pendek di 1,44 dtk (cegukan pertama, di jeda sebelum "Eh"). Tidak ada efek "hik" di 5,13 dan 19,74 (hanya suara narator); stem efek di jendela itu bernilai 0 (5,0 - 5,4) dan sangat kecil (tok rendah 19,48, puncak 0,05 pada 19,6 - 19,9).
- **Urutan anatomi**: orientasi tetap di seluruh video (paru-paru di atas, diafragma melengkung di bawah, laring di leher). Diafragma: pita emas kontras terhadap paru muda dan organ coklat; satu kontraksi singkat (kubah turun ~44 px dunia, paru melebar 2,8%, hati/lambung turun <= 16 px), tidak ada organ meloncat atau berubah ukuran ekstrem. Kamera: Raka -> dada -> penampang -> diafragma -> naik lewat trakea -> laring (zoom 5,2x) -> mundur -> Raka. Peta mini "1 diafragma, 2 pita suara" menjaga hubungan dua adegan.
- **Audio** (ebur128): edukasi 0 - 30 dtk -14,7 LUFS; bagian outro dalam file akhir -14,4 LUFS / puncak sampel -1,3 dBFS (sama dengan spesifikasi master -14,4 / -1,4); gabungan -14,6 LUFS, puncak sampel -1,0 dBFS. Tidak ada `loudnorm` pada file gabungan. Stem suara berakhir 27,8 dtk; musik dan efek berakhir bersih sebelum 30,0 dtk (sampel terakhir edukasi ≈ 0), jadi tidak ada tumpang tindih dengan narasi master. Envelope RMS outro dalam file akhir cocok dengan master (di-encode ulang ke AAC sesuai README master, jadi tidak identik per sampel).
- **Sambungan**: frame 0 outro cocok dengan frame 0 master (selisih 0,12) dan frame terakhir dengan frame terakhir master (0,13) pada skala 0 - 255; potongan keras dari frame terakhir edukasi (Raka lega, kartu ringkasan) ke Atlas 3D, tanpa logo/CTA buatan di antaranya. URL medcoel.com terbaca di bagian master (still `outro-39_00s.jpg`, `outro-45_90s.jpg`).
- **Layar ponsel / area aman**: judul dan label di atas y 250; takarir di y 1306 - 1402; tidak ada teks di tepi kanan bawah. Diperiksa pada lembar 270 px dan 360 px (`still/lembar-270px.png`, `cover/cover-360px.png`): judul, takarir, label (>= 34 px), kartu, dan "HIK!" terbaca. Angka 1/2 pada peta mini (19 px) dan nomor kartu kecil, tetapi kata "diafragma/pita suara" pada peta mini 30 px.
- **Raka**: seluruhnya dari `rakaSvg()`, patch logo terlihat, proporsi lengan/tangan dari pose resmi (lengan memakai `armTo` hanya mengatur pergelangan). Latar krem/kayu: sweater teal tidak melebur.
- **Fakta**: dibandingkan dengan dua rujukan MedlinePlus (lihat `SUMBER.md`); tidak ada klaim cara menghentikan cegukan, penyakit, atau "selalu menyebabkan".

## Putaran koreksi
1. Meja diperpanjang sampai tepi bawah (frame 0 sebelumnya memperlihatkan krem di bawah meja), zoom hook dikurangi agar rambut Raka tidak menabrak judul, pensil dibuat terlempar saat cegukan pertama.
2. Kartu pemicu: ikon terpotong dan lambung mirip kentang -> kartu 350 px, ikon diperkecil, ditambah kerongkongan dan usus; pil "BISA MEMICU" dipindah agar tidak menutupi rambut Raka.
3. Dasar penampang dada diperpanjang (sebelumnya berakhir datar di tengah layar); peta mini diperbesar; tok kontraksi ulang digeser dan dilemahkan agar tidak menimpa "hik" narator.

## Keterbatasan yang jujur
- **Saya tidak dapat mendengar audio atau menonton video pada kecepatan normal.** Sinkron suara-visual diperiksa lewat waktu kata ASR (faster-whisper), puncak energi, selisih frame, dan lembar kontak. Efek "hik" sintetis (desah + vokal "i" + penutupan) belum diaudisi telinga; mohon didengar sebelum tayang, dan ganti `hik()` di `audio/audio_mix.py` bila kurang natural.
- Naskah hanya punya satu "penutupan" dan dua "hik" narator. Agar bunyi tepat pada penutupan, urutan penutupan diperlihatkan dua kali (16,16 untuk "menutup dengan cepat", lalu ulangan pada "hik" 19,74 yang dibunyikan narator).
- Ekor 2,2 dtk (27,8 - 30,0) tanpa suara: dipakai untuk ringkasan tiga ikon agar edukasi mencapai ~30 dtk dan kalimat terakhir selesai bersih; total 46,2 dtk (batas bawah rentang 46 - 52).
- Panah udara turun lewat trakea adalah penyederhanaan animasi (tidak dijabarkan sumber); ukuran organ, skala, dan kecepatan gerak bersifat ilustratif.
- ASR salah dengar "diafragma" ("dia Fragma") dan "penyebab" ("penjabat"); takarir memakai ejaan naskah pemesan.
