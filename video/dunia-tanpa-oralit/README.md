# Video "Dunia tanpa oralit"

`medcoel-dunia-tanpa-oralit.mp4`: 1080x1920, 30 fps, 87,0 detik. Naskah dan storyboard: `NASKAH.md`.

- Suara: dua audio ElevenLabs asli (`audio/source/`), dipotong di jeda antar-giliran sesuai ID N01–N10 dan O01–O04. Tidak ada suara baru, tidak dipercepat, tidak ada kata terpotong. Hanya volume yang disamakan antara dua suara.
- Karakter: `stage/rig.js`. Lengan dan kaki berupa satu pita lengkung berwarna sama dengan baju (tanpa lingkaran sendi), kepala terikat ke badan lewat leher, kolong meja tertutup taplak.
- Visual cairan: `stage/body.js`, metafora tabung berisi air (biru) dan elektrolit (berlian emas), tanpa angka.
- Maskot Kori dari `brand/mascots/kori.svg`, tidak diubah. Musik dan efek sintesis (`audio/music.py`), di bawah dialog lewat sidechain, hasil sekitar -16 LUFS.
- Membuat ulang: `bash build.sh`.
