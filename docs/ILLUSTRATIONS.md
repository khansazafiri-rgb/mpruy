# MEDCOEL illustration collection

Generated with the built-in image generation tool. Decorative editorial illustrations, not clinical diagrams. The selected anatomy image is the style reference for every other asset. The earlier 3D concept is not used.

All 34 optimized assets live in `apps/web/public/illustrations/`. Admin uploads remain supported and take priority; unknown subjects use `umum.webp`.

## Shared prompt

Use case: illustration-story. Asset type: landscape illustration for a premium medical learning subject card. Create a charming TWO-DIMENSIONAL editorial illustration with character and personality. Hand-drawn flowing dark emerald outlines of subtly varying weight, flat warm ivory fills, restrained sage and deep green (#007060) shapes, tiny muted golden yellow (#F8C038) accents, very subtle paper grain. Rounded expressive forms and slightly imperfect curves, sophisticated friendly magazine illustration, playful but composed. Flat ivory (#F8F7F3) background, centered complete subject, generous negative space. Consistent icon scale and line weight across collection. Absolutely NOT realistic, NOT photorealistic, NO 3D, NO sculpture, NO glossy material, NO rendered lighting, NO gradients, no text, no lettering, no logo, no watermark. One illustration, not a grid.
